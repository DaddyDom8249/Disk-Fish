1. CORE PRODUCT

The application analyzes a disc-golf player's throwing mechanics from video.

A user records or uploads a throw.

The system must:

1. Import video.
2. Validate video quality.
3. Determine throwing direction/type when possible.
4. Detect the athlete.
5. Track the athlete through the complete throw.
6. Extract body landmarks.
7. Analyze movement frame-by-frame.
8. Detect throw phases.
9. Calculate biomechanical measurements.
10. Analyze sequencing and timing.
11. Analyze the throwing arm.
12. Analyze lower-body mechanics.
13. Analyze torso rotation.
14. Analyze plant/bracing mechanics.
15. Analyze release mechanics.
16. Analyze disc motion when detectable.
17. Compare the measurements against professional reference data.
18. Identify the largest meaningful differences.
19. Produce prioritized coaching feedback.
20. Show the user exactly what was detected and how confident the system is.
21. Allow the user to rethrow and measure improvement over time.

The system must NEVER invent measurements.
